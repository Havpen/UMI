# UMI — спецификация сайта для разработки

Документ для Cursor и программиста. Это единый источник правды по BA и SEO на 16.08.2026. Word-файлы в `docs/` — черновики процесса; **код писать только по этому файлу**.

Если решение ниже помечено **зафиксировано** — не переспрашивать и не менять без BA. Если **допущение** — можно верстать, перед продом сверить. Если **позже** — не блокирует первую вёрстку.

---

## 0. Как пользоваться в Cursor

1. Открыть папку `Umi` как workspace.
2. В начале работы прочитать этот файл целиком.
3. Не подтягивать визуал с wok.by, aggregators, Aesop, Muji, тёмных «премиум-Азия» шаблонов.
4. Не выводить алкоголь ни в меню, ни в мета, ни в alt, ни на фото-акцентах бара.
5. Не строить полноценный интернет-магазин с оплатой. Заказ с сайта = заявка в Telegram.

Стек не зафиксирован. Если не задан — современный SSG/SSR (Next.js / Nuxt / Astro) + адаптив mobile first. Контент меню на старте можно держать в JSON/MD, админка — позже.

## 3. Что делает сайт v1

Главное действие — **бронь стола**. Второе — **заказ на вынос заявкой**. Доставка агрегаторами — ссылки, не наша корзина.

| Входит в v1 | Не входит в v1 |
|---|---|
| Визитка зала, меню на сайте, ланч, бранч | Полноценная админка |
| Шторка брони → Telegram + почта | Эквайринг, 54-ФЗ, онлайн-касса |
| Лёгкая корзина выноса → заявка в Telegram | Интеграция iiko / r_keeper |
| Ссылки на Яндекс Еду, just-eat.by, clever.by | Личный кабинет, бонусы, промокоды |
| Карта, отзывы, о нас, интерьер | Банкеты / мероприятия |
| SEO-страницы категорий | Алкоголь в любом виде |
| | Отдельные лендинги на улицы города |
| | SMS-шлюз «заказ принят» без человека |

Сайт **не ждёт** готового Telegram-бота-магазина. Бот на старте = чат, куда падают заявки. Каталог в боте можно делать параллельно, не дублируя цены.

## 4. Визуал (для вёрстки до макетов)

- Фон: **мягкий тёплый белый** (молоко / фарфор), не чистый `#FFFFFF`, не чёрный.
- Liquid glass: **светлая** матовая панель на шапке, кнопках, шторке, плавающей брони. Не стекло на всём меню.
- Текст и цены — всегда непрозрачные, тёмный контраст.
- Fallback: если `backdrop-filter` тормозит Safari/Android — сплошная панель 80–90% opacity. Учитывать `prefers-reduced-transparency` и `prefers-reduced-motion`.
- Азия — в еде и зале, не в драконах, красном лаке, иероглифах на каждом экране.
- Hero главной: **сразу наше атмосферное видео зала**, как только открыли сайт. Не статичное фото вместо ролика. Постер — только пока файл грузится и для `prefers-reduced-motion`. Без звука, loop, playsinline (iPhone). На мобиле тоже видео; сжимать (mp4 + webm), не отдавать исходник 40 МБ.
- Hero-видео проверить: не акцентировать бар и бутылки (закон РБ о рекламе алкоголя).
- Карточки блюд: фото, имя, цена; описание — в карусели категории и в шторке. Пока нет фото блюда — спокойный плейсхолдер в тоне интерьера, не сток.

## 6. Главная — блоки сверху вниз

1. **Hero.** Первое, что видит гость при открытии `/` — **атмосферное видео зала** (уже снято). Поверх — светлый UI, H1 формула. Кнопки **столбиком**:  
   - основная: «Забронировать стол» → шторка;  
   - под ней тише: «Заказать на вынос» → `/menu` в режиме выноса или якорь + корзина.
2. **Меню хитов.** Карусель 12 позиций (раздел 7). Ссылка «Всё меню».
3. **Заказать с доставкой.** Ряд логотипов агрегаторов (как Station). Коротко: доставку везут они; на вынос можно оформить у нас. Ссылки — §10, без UTM.
4. **Ланч и бранч.** Две тихие плитки (клиент блок не обсуждал — **оставляем**, иначе дневной сценарий пропадает). Ссылки `/lunch`, `/brunch`.
5. **О нас и интерьер.** Короткий текст + фото/кадры зала и открытой кухни.
6. **Отзывы + карта «как найти»** в духе Ultima Guide + адрес, часы, телефон, Instagram.

Плавающая pill «Забронировать» на mobile после скролла hero — светлое стекло.

## 8. Полное меню (IA)

Гостю PDF не показываем. Источник правды для команды — PDF от 16.08.2026; на сайте — карточки.

Табы / подвиды:

1. Закуски и стартеры (соусы как дополнение внутри)
2. Салаты и поке
3. Супы
4. Основные: воки, паста, горячее
5. Суши и роллы: нигири, роллы, запечённые, темпура
6. Десерты
7. Напитки: горячие (кофе, чай, матча) / холодные (милкшейк, смузи, фреши, лимонады, сезонные, в упаковке)
8. Бизнес-ланч
9. Бранчи

На `/menu` и на посадочных: таб включает **карусель блюд этой категории** (паттерн Strekoza) с описанием и ценой.

**Контент-дырка:** в спецификации есть 12 хитов с ценами. Остальные блюда, веса, описания, фото — **когда пришлют**. Верстать каркас категорий и 12 хитов. Пустые категории не публиковать в индекс (noindex или не создавать URL, пока нет блюд) — десерты и напитки не индексировать, пока нет позиций.

Аппетитные описания блюд не выдумывать.

## 9. Бронь

Шторка (bottom sheet на mobile; справа или центр на desktop). URL `/booking` открывает ту же шторку.

Поля: имя, телефон, дата, время, число гостей, комментарий. Согласие на обработку ПДн (когда будет политика).

Текст кнопки: «Отправить заявку».  
После: «Заявку получили, подтвердим по телефону.»  
Заявка ≠ бронь.

Куда: Telegram администратору + email. Эндпоинт/бот — переменные окружения, не хардкод токена.

## 10. Вынос (свой заказ) и доставка (чужая)

Это **два пути**.

### Вынос UMI

1. Гость выбирает блюда из того же меню сайта (не PDF).
2. Лёгкая корзина: позиция, количество, сумма.
3. Форма: телефон, время получения, комментарий. Адрес в v1 не обязателен (это вынос). Если позже включат свою доставку — поле адреса показать только тогда.
4. «Отправить заявку» → сообщение в Telegram кухне/админу: список, кол-во, сумма, телефон, время.
5. Гостю на экране: «Заявку получили, подтвердим по телефону.»

Не делать: эквайринг; SMS «заказ принят»; статусы как у Еды; отдельный каталог в боте с другими ценами.

### Доставка агрегаторов

Блок логотипов-ссылок. Открывать в новой вкладке (`rel="noopener noreferrer"`). Событие `click_aggregator` с параметром имени сервиса. **Не использовать** ссылки с `utm_`, `yclid`, `etext` — только канонические URL:

| Сервис | URL |
|---|---|
| Яндекс Еда | https://eda.yandex.by/gomel/r/restoran_umi_restaurant |
| just-eat.by | https://just-eat.by/umi-gomel |
| clever.by | https://clever.by/gomel/umirest-delivery/ |

Заглушки `#` недопустимы. Блок на проде показываем: ссылки есть.
